Build Your First AI Chatbot

Objective
Learn how to integrate a Large Language Model (LLM) API and build a simple conversational AI chatbot.
Description
In this task, you will create your first AI-powered chatbot using an LLM API (OpenAI, Gemini, or Claude). The chatbot should accept user input, send requests to the model, and display meaningful responses through a simple interface.
This task introduces you to the fundamentals of working with modern AI applications.
Tasks
Create a new GitHub repository.
Integrate an LLM API.
Build a simple chat interface.
Handle API errors gracefully.
Maintain conversation history.
Add a loading indicator while generating responses.
Organize the project structure.
