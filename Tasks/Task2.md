Build a RAG System

Objective
Build a Retrieval-Augmented Generation pipeline capable of answering questions using external documents.
Description
Develop an AI assistant that retrieves relevant information from uploaded PDF documents before generating answers.
Tasks
Extract text from PDFs.
Split documents into chunks.
Generate embeddings.
Store embeddings in a vector database.
Retrieve relevant chunks.
Generate context-aware answers.
